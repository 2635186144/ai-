## 如何体验

1. 按[仓库README](../../README.md)安装依赖、构建前端并启动系统。
2. 首次体验建议选择3页的人才培养研究，在工作台点击“上传 PDF”，选择本目录中的文件。
3. 无API Key时，可体验本地解析、题名与章节识别、原文定位和图表预览。图表是否完整仍需结合原页核对。
4. 若要生成全文解读，先在本机后端配置有效模型与API Key，再确认发送范围及请求预算。提取文字、页码、位置及阅读笔记会发送给配置的模型服务商，费用由使用者账户承担。
5. 可再尝试区块链主题论文，查看方法、指标、图表与创新点对照；其余三篇用于比较不同研究类型的阅读方式。

## 材料说明

- 本目录只包含PDF和文件清单，不包含历史报告、阅读笔记、评测答案、数据库或作者的API Key。首次启动仍为空资料库，不会自动导入或自动调用模型。
- 这些是真实论文，非本项目合成测试数据；论文观点、图表及著作权归原作者和相应权利人。仓库中的应用代码许可不替代第三方论文自身的权利安排，作者及出版信息以PDF为准。
- 样品用于功能体验，不是独立留出评测集，不能据此推断系统具有特定准确率、已验证研究结论或完成独立新颖性判断。
